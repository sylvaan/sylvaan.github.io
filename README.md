Frontend developer portfolio showcasing web and mobile applications, primarily focused on healthcare and enterprise sectors.

**[🌐 View Live Website](https://sylvaan.github.io)**

## 🛠 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **UI Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion

## 🏗️ Folder Structure

- `src/app/`: Page layouts and routing.
- `src/data/`: Centralized project and experience metadata.
- `public/`: Project assets and images.

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sylvaan/sylvaan.github.io.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **View the project:**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📝 Features
- **Project Filtering:** Case-sensitive filtering for professional and personal projects.
- **Responsive Layout:** Optimized for desktop and mobile viewports.
- **Scroll Animations:** Entrance animations triggered on viewport entry.
